1. Executive Summary
SteppeGuard is a real-time AI-powered geospatial monitoring platform that detects active wildfires and tracks land degradation across the Kazakh steppe using free satellite data from the European Space Agency's Sentinel-1 (SAR) and Sentinel-2 (optical) missions. It addresses a critical monitoring gap: Kazakhstan has over 90 million hectares of degrading steppe — a biome that is poorly served by existing forest-fire tools — and suffers recurring seasonal wildfires that cause massive ecological and economic damage.
The system provides district-level wildfire risk scoring updated every 12 hours, a 48-hour fire spread prediction model, an interactive geospatial dashboard with heatmap and interconnected mindmap visualisations, and automated SMS/email alerts for high-risk districts. The entire data pipeline uses exclusively free, open-access satellite data and APIs, making it immediately deployable on free cloud tiers.
One-Line Pitch
SteppeGuard uses Sentinel satellite fusion and a hybrid ML pipeline to give Kazakhstan's first AI-powered 48-hour wildfire early warning — directly from space, at zero data cost.
Problem Statement
Kazakhstan faces three compounding crises that SteppeGuard directly targets:
Land degradation affects 66% of Kazakhstan's territory (90M+ hectares). Existing NDVI-based tools fail in steppe because the spectral signature of degraded grassland saturates NDVI — making degradation invisible to standard tooling.
Steppe wildfires: Unlike boreal or tropical forests, Kazakh steppe fires spread at extreme speed with almost no canopy coverage to slow them. Existing early-warning systems (designed for forests) miss early ignition signatures in grassland.
No regional AI solution exists: Global platforms (NASA FIRMS, Copernicus EMS) provide raw fire detection but no spread prediction, no degradation-integrated risk scoring, and no localised alert system for Kazakh administrative districts.
Solution Overview
SteppeGuard solves this through a 3-layer technical approach:
Detection Layer — Spectral index pipeline (NBR, BSI, NDVI, BAI) on Sentinel-2 + SAR backscatter change detection on Sentinel-1. These two signals are fused to produce a per-pixel Fire Probability Score that works even under cloud/smoke cover.
Prediction Layer — Random Forest model trained on historical Kazakhstan fire events (2019–2024) with wind, temperature, humidity, slope, and vegetation features. Outputs 48-hour spread probability maps.
Presentation Layer — React dashboard with Leaflet heatmap + React Flow mindmap showing causal relationships between risk factors (wind → dry vegetation → ignition probability → district risk → alert status).

F1 + F2 + F3: Detection & Heatmap Engine (Most Critical)
The heatmap is the first thing judges see. It must show real satellite-derived data — not mock data. Here is exactly how it works:
Spectral Indices Computed per Sentinel-2 Scene
Index Formulae
Index
Formula
What it detects
Threshold
NBR
(NIR - SWIR2) / (NIR + SWIR2)
Active burn scars, char
< −0.10 = burned
dNBR
NBR_pre − NBR_post
Change detection, severity
> 0.27 = high severity
BAI
1 / ((0.1 − RED)² + (0.06 − NIR)²)
Active flame, thermal emissivity
High value = active fire
BSI
((SWIR1+RED) − (NIR+BLUE)) / ((SWIR1+RED) + (NIR+BLUE))
Bare soil / degradation
> 0.0 = exposed soil
NDVI
(NIR − RED) / (NIR + RED)
Vegetation health / fuel load
< 0.2 = low fuel, < 0.1 = degraded
SAR Fusion Logic
Sentinel-1 VV polarisation backscatter change (pre-fire vs. current) is computed as:
SAR_change = (sigma_pre - sigma_current) / sigma_pre
# Decrease in backscatter = vegetation loss = fire/degradation signal
# Fusion Score (0-100)
fusion_score = 0.40 * normalize(dNBR)
             + 0.25 * normalize(BAI)
             + 0.20 * normalize(SAR_change)
             + 0.15 * normalize(BSI_anomaly)

F5: React Flow Risk Mindmap
This is SteppeGuard's most visually unique feature. Unlike static dashboards, the mindmap shows the causal chain from environmental inputs to district alert status as animated floating nodes with weighted edges. No competing team will have this.
Mindmap Node Architecture
ROOT NODE: District Name + Current Risk Level (colour-coded badge)
LEVEL 1 NODES: Wind Conditions | Vegetation State | Historical Risk | SAR Signal | Weather Forecast
LEVEL 2 NODES: Wind Speed | Wind Direction | NDVI Value | dNBR Score | Fire Count (5yr) | Temperature | Humidity
EDGES: Weighted by contribution to risk score. Animated pulse when value is in danger zone.
INTERACTIVITY: Click any district on map → mindmap updates to show that district's causal graph.
LAYOUT: Dagre auto-layout with custom node colours: GREEN (safe) → AMBER (watch) → RED (danger) → DARK RED (critical)
